# RadarSec

Este projeto foi desenvolvido como método de avaliação para a disciplina de **Projeto Prático 2** do curso de **Cibersegurança**.

## O que é?
O **RadarSec** é uma plataforma web centralizada para o gerenciamento de projetos e incidentes de segurança da informação, desenhada para facilitar o trabalho de times de resposta a incidentes e analistas de segurança.

## O que faz?
A aplicação oferece as seguintes funcionalidades principais:
- **Gestão de Projetos:** Criação e organização de escopos de projetos de cibersegurança, definindo responsáveis e centralizando o contexto.
- **Registro de Incidentes:** Abertura e acompanhamento de incidentes de segurança associados aos projetos, com classificação de status, severidade e atribuição de responsáveis.
- **Gestão de Evidências:** Capacidade de anexar, visualizar e baixar arquivos (logs, capturas de tela, relatórios) que servem como provas ou artefatos para a investigação de cada incidente.
- **Controle de Acesso:** Sistema de autenticação segura e controle baseado em papéis (Administrador e Usuário), garantindo a proteção e o isolamento adequado dos dados registrados.
